日期：2026-09-19。制作方式：内置 image_gen，根据 GDD v2.0 制作的原创图像初稿。原始 PNG 保留，不进行程序抠图或重绘。准确提示词、原图尺寸、透明度检查和 SHA-256 见同目录 `asset_manifest.json`。

## 内容与入口

- 山房固定视角背景 1 张：雨窗、木案、青瓷、暖灯。
- 茶品链 5 张、青瓷链 5 张：独立透明 PNG，对应策划配表中的稳定 itemId。
- Elena 半身头像 1 张：透明 PNG，平静倾听表情。
- 每日卡共用底图 3 张：雾山、水纹、竹影。卦象和文字由界面绘制，图片中不烘焙文字或卦爻。

在 Unity 中选择 **Yijing → Art → Open Asset Preview** 浏览全部图片。`Assets/Yijing/Data/ArtCatalog.asset` 汇总引用；后续棋盘用 `FindItem(itemId)` 查找 Sprite。

打开本目录 `preview.html` 可查看浏览器预览，切换深浅背景并将物品缩至实际棋盘尺寸，检查轮廓与透明边缘。

## Unity 导入

选择 **Yijing → Art → Import and Validate**，设置二维纹理与 Sprite（2D and UI）、Single、100 PPU、Full Rect、Bilinear、Clamp、不生成 Mipmap；保留源透明通道，物品与人物开启 Alpha Is Transparency。

物品导入上限 512，人物 1024，场景和卡底 2048。原文件保持生成分辨率；Max Size 是上限，不会补出缺失的细节。当前使用默认高质量压缩，正式移动版须在 Android/iOS 真机上再评估 ASTC 压缩和透明边缘表现。

背景使用保持比例的 cover 布局，卡片保持 9:16；禁止非等比拉伸。图标的 UI 格子与碰撞区域固定，图片置于内边距中，文字和等级徽标由 UI 单独绘制。棋盘推荐米白或深灰绿底，图标缩小后仍保留阶数提示，不能只依赖纹理识别。

## 制作边界

山房是单张平面基底，灯、泉、铜铃等已画在图中，暂不能作为独立修葺开关或视差层。它适合初版场景和风格确认；正式建设前后状态需要另外制作干净基底及可独立开关的叠层。

Elena 当前只有一种表情；后续表情应以本图作身份参考，保留面部、发型和服装一致性。没有制作逐帧人物动画或骨骼绑定。

三张卡底用于八卡共用排版，不代表八幅卦象原画。六爻顺序、卦名、反思文字和日期全部取自程序配置，禁止把生成图片当作卦象数据来源。

此批没有音频、字库、正式商店图或完整动效。生成图像经过初次视觉和透明度检查，仍需在真实棋盘、不同手机尺寸和最终字体上验收；不得把本批交付等同于完整游戏已完成。

## 本次验证

15 张原图均已检查。11 张物品／人物 PNG 确认具有真实 Alpha，3 张卡底和山房为不透明背景；在预览页检查了 80 px 图标及深浅底色。Unity 6000.6.0f1 在独立副本中编译成功，15 个 Sprite 引用与 10 个物品 ID 映射校验通过。当前打开的主工程与场景未被关闭。

生成源尺寸：图标和头像为 1254 × 1254；山房及三张卡底为 941 × 1672，比例接近 9:16。若导出 1080 × 1920 分享图，背景需约 1.15 倍放大；正式高分辨率宣传图仍需更高分辨率素材，不能仅凭导入上限声称原生 2K。
