# 首段可玩版试玩说明

版本：0.3.0 故事与引导版。项目路径 `/Users/luca/YJGPT`，Unity 6000.6.0f1。

已有存档请点右上角“引导 → 从头练习 · 不影响当前进度”，再从两页开场开始；练习可以随时退出。新玩家直接跟随顶部目标和描边即可，不需要先读下面的操作步骤。

## 启动

在 Unity 打开 `Assets/Yijing/Scenes/Bootstrap.unity`，等待编译完成后点击 Play。Game 视图选择 9:16 或 540×960，体验更接近目标竖屏；其他窗口比例会保留完整竖屏内容。

也可运行本机 `Artifacts/Build/Yijing.app`（已验证的 0.3.0 包；最后两处纯文案修整待 Unity 授权恢复后重建，详见 VALIDATION.md）。桌面包和编辑器使用同一份正常存档；不建议两边同时进行游戏，以免各自的快照相互覆盖。本轮自动化测试全部使用隔离存档。

## 先用约十分钟试这一轮

1. 点击“茶台”两次，将两撮山茶拖到一起，得到一包山茶；器架和静／行选项应随即开放。
2. 继续合成。两包山茶得到“小罐清茶”（三阶）。第一单选“静”，准备两件小罐清茶，点击交付，确认消耗清单。
3. 第一单完成后灵石应为 46。打开“山房 · 门边灯”，花 40 灵石点灯，应剩 6，房间色调变暖。
4. 点灯后进入第二单。“静”需要一包山茶×2＋青瓷茶杯×1；第三单选“行”（小罐清茶＋青瓷茶杯）。完成三单后应剩 38 灵石，送别 Elena，再得到“第 15 卦 · 谦”。六爻从上往下显示三阴、阳、阴、阴。
5. 停止 Play，再次进入。棋盘、储物、灵石、灯和卦卡应恢复。第三单后显示首段结束，两个常客请求仍可继续交付；当天不会重抽另一张卡。

拖拽不便时，可先点物品，再点目标格。移至空格为移动，移至不同物品为交换，第五阶不再升级。拖出棋盘不提交操作。

## 再检查这几个边界

- 选中物品后点击“存入储物架”；取消棋盘选择后点击“储物架”查看，选择物品取回。
- 交付默认只消耗茶案物品。只有在确认界面主动开启“储物架供货”，才会取用存下的物品。
- 选中物品“放回工具台”，会折回相同链的基础当量；不产生灵石。立即“撤销回收”应恢复同一件物品和原位置。之后生产优先扣基础库存。
- 填满 42 格后，继续生产会提示满盘；合成、交付、存入储物或回收仍然可用。
- 第四份有效交付仍有灵石，但不改变当天三爻。次日新交付进入新记录；原日记录可在手账中翻阅。
- 操作保存失败时不得显示交付成功；损坏主存档会尝试上一份备份，两份均无效时停止加载并保留文件。
