# 雨夜茶舍试玩说明

源码版本 0.4.0。项目：`/Users/luca/YJGPT`，Unity 6000.6.0f1。

**当前构建状态：新版已写入工程，但 Unity 授权尚未恢复，未完成播放模式和画面声音验收。`Artifacts/Build/Yijing.app` 仍是 0.3.0，不包含本次茶舍改造。**

## 启动与练习

恢复 Unity Hub 登录与许可证后，打开 `Assets/Yijing/Scenes/Bootstrap.unity`，等编译完成，点击 Play。建议 Game 视图使用 9:16 或 540×960。

已有进度可以在茶舍右上角“引导 → 从头练习”进入独立体验。开场的“退出练习”或茶舍右上角的引导入口可返回原存档；在茶案上则点“退出练习”。不要删存档。

## 先自由体验

先不看下面流程，留意：是否愿意待在茶舍；有没有听到雨与器物声；是否觉得倒茶太慢；是否仍在找下一步按钮；是否只想快速完成清单。声音、动态可以分别关闭。

“听雨”没有奖励或倒计时，也不会自动交付；始终可以点“回到茶舍”。

## 功能核对

1. 开场在茶舍中迎客，进入茶案；第一单静只需两件 T2（一包山茶），即 4 次取茶、2 次合成。
2. 点“备好 · 端茶”，放杯、倒茶，然后递给来客。倒茶可以跳过；递出前退出不扣任何物品。
3. 第一次交付后为 38 灵石；点灯花 30，剩 8。灯亮后再准备第二席。
4. 第二席静为 T2 + C2；第三席行为 T2 + C2。静／静／行三单完成后为 24 灵石，同日记录对应第 15 卦谦。
5. 送别后可以继续听雨，或自愿打开手账。重新进入应恢复进度和场景物件。
6. 在来客回应中先听雨，再返回，应该继续显示尚未读完的回应。不会再扣物品或发奖。
7. 返回茶案仍可使用储物、免费回收与撤销。满盘可恢复，高阶不能替代低阶。常客入口在首幕完成后的茶舍或茶案标签中。
8. 核对静音、动态关闭、后台静音及恢复；在手机上检查文字、触控和安全区。

正常存档仍为 `Application.persistentDataPath/tea-room-v1.json`，兼容 schema 1／2，原存档物品和余额保留。编辑器与旧 app 使用同一正常存档，不要同时游玩；所有自动检查使用隔离进度。

范围仍为三单首幕和四个常客模板。完整十八单、其他修葺、人物动作、最终声音、英文、手机发布和分享导出尚未完成。
