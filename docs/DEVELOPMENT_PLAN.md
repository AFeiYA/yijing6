## M1 棋盘规则与灰盒

1. **规则状态**：7×9 棋盘，先开放 7×6；稳定实例 ID 与修订号。禁止用场景对象作为状态源。
2. **产出与拖拽**：盘外 T1/C1 产出，默认首个空位；移动、交换、同物二合、五阶终点；锁格和无效落点不改变状态。
3. **恢复路径**：满盘不产出；储物、免费回收、返还基础当量和撤销；资源总当量守恒。
4. **灰盒界面**：竖屏安全区、目标预览、生产按钮、触控拖拽，先占位图；不以正式美术阻塞规则验证。
5. **订单**：E01 至 E03 + 4 个常客模板；静行变体可切换、成本等价、高阶不自动代替低阶。

验收：重复输入不复制资源；满盘可恢复；退出前后状态一致；真机连续操作无明显误触。
